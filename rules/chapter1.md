# Chapitre 1 — Création de personnage

Ce chapitre présente les règles fondamentales permettant de créer un personnage joueur.

Le jeu utilise le système **D6** avec des dés et des pips. Les personnages sont créés selon une méthode à limites définies.

Cette méthode est destinée à des joueurs expérimentés et constitue la méthode de création standard du jeu.

---

## 1. Création à limites définies

Chaque personnage reçoit :

* **18D à répartir entre ses attributs** ;
* **7D à répartir entre ses compétences**.

Les dés peuvent être divisés en pips.

Un dé équivaut à trois pips :

* 1D = 3 pips ;
* 2D+1 = 7 pips ;
* 2D+2 = 8 pips ;
* 3D = 9 pips.

Les pips permettent une progression plus fine que l'ajout d'un dé entier.

---

# 2. Les attributs

Chaque personnage possède six attributs.

## Agility

**Agility** représente la coordination, la précision, les réflexes et les capacités physiques liées au mouvement.

Elle sert notamment aux actions impliquant :

* la coordination ;
* les réflexes ;
* le tir ;
* le combat rapproché ;
* l'esquive ;
* la mobilité physique.

---

## Strength

**Strength** représente la puissance physique, l'endurance et la résistance naturelle du personnage.

Elle intervient notamment pour :

* soulever ou déplacer des objets ;
* résister à la fatigue ;
* nager ;
* grimper ;
* effectuer des efforts physiques ;
* résister aux dommages.

---

## Knowledge

**Knowledge** représente les connaissances, l'apprentissage et la compréhension intellectuelle du personnage.

Elle couvre notamment :

* les connaissances académiques ;
* les langues ;
* la survie ;
* la navigation théorique ;
* les connaissances professionnelles ;
* les connaissances techniques ou scientifiques théoriques.

---

## Perception

**Perception** représente la conscience de l'environnement, l'utilisation des sens et la capacité à interpréter les informations.

Elle couvre notamment :

* l'observation ;
* la recherche ;
* l'investigation ;
* la discrétion ;
* les interactions sociales ;
* le commandement ;
* la persuasion.

---

## Mechanical

**Mechanical** représente la capacité à utiliser et contrôler des véhicules et des systèmes mécaniques complexes.

Il couvre notamment :

* le pilotage ;
* la navigation ;
* les systèmes de véhicules ;
* les capteurs ;
* les communications ;
* les armes montées ;
* les boucliers ;
* les systèmes de vaisseaux.

Mechanical représente la capacité à **utiliser une machine**.

---

## Technical

**Technical** représente la capacité à construire, réparer, modifier et entretenir des systèmes technologiques.

Il couvre notamment :

* la réparation ;
* l'ingénierie ;
* l'informatique ;
* la médecine technique ;
* la maintenance ;
* la modification d'équipements ;
* la réparation de véhicules ;
* la réparation de systèmes électroniques.

Technical représente la capacité à **comprendre et modifier une machine**.

---

# 3. Répartition des attributs

Le joueur dispose de **18D** à répartir entre les six attributs.

Chaque attribut doit avoir une valeur comprise entre :

* **Minimum : 1D**
* **Maximum : 5D**

Les pips peuvent être utilisés lors de la répartition.

Un personnage moyen posséderait théoriquement une valeur de 3D dans chaque attribut :

| Attribut   | Valeur moyenne |
| ---------- | -------------: |
| Agility    |             3D |
| Strength   |             3D |
| Knowledge  |             3D |
| Perception |             3D |
| Mechanical |             3D |
| Technical  |             3D |

Cette répartition représente un personnage équilibré.

Le joueur peut cependant spécialiser son personnage en augmentant certains attributs au détriment d'autres.

### Exemple

| Attribut   | Valeur |
| ---------- | -----: |
| Agility    |   3D+1 |
| Strength   |   2D+1 |
| Knowledge  |     3D |
| Perception |     3D |
| Mechanical |   4D+2 |
| Technical  |   2D+2 |

Total : **18D**

---

# 4. Les compétences

Les compétences représentent l'entraînement et l'expérience spécifique d'un personnage.

Chaque compétence est associée à un attribut.

Par défaut, une compétence possède la même valeur que son attribut associé.

### Exemple

Un personnage possède :

> Technical 2D+1

Sans entraînement particulier, ses compétences techniques sont également utilisées à :

> 2D+1

Le joueur peut ensuite augmenter une compétence grâce aux dés de compétences reçus lors de la création du personnage.

---

# 5. Répartition des compétences

Chaque personnage reçoit **7D** à répartir entre ses compétences.

Les dés peuvent être divisés en pips.

Une compétence peut donc évoluer ainsi :

```text
2D
2D+1
2D+2
3D
3D+1
```

Les dés de compétences représentent une amélioration par rapport à l'attribut de base.

### Exemple

Un personnage possède :

> Technical 2D+1

Il investit un pip dans la compétence Demolitions :

> Demolitions 2D+2

Il investit ensuite deux pips supplémentaires :

> Demolitions 3D+1

---

# 6. Limite de compétence à la création

Lors de la création du personnage, une compétence ou une spécialisation ne peut recevoir plus de **3D supplémentaires**.

Cette limite représente la formation et l'expérience acquises avant le début de la campagne.

---

# 7. Les spécialisations

Une spécialisation représente une expertise dans un domaine plus précis d'une compétence.

Elle est facultative.

Un personnage peut être compétent dans un domaine général ou développer une expertise spécifique.

### Exemple

Un personnage possède :

> Piloting 4D

Il peut développer une spécialisation :

> Piloting : Spacecraft 5D+1

La spécialisation est utilisée lorsqu'elle correspond précisément à la situation.

Une spécialisation peut également être acquise indépendamment d'une amélioration importante de la compétence générale.

---

# 8. Philosophie des attributs et compétences

Le système distingue volontairement les capacités générales et les compétences acquises.

## Attribut

L'attribut représente :

* les capacités naturelles ;
* les aptitudes générales ;
* les prédispositions du personnage.

## Compétence

La compétence représente :

* la formation ;
* l'expérience ;
* la pratique ;
* la spécialisation.

Ainsi, deux personnages peuvent posséder le même attribut tout en ayant des compétences très différentes.

### Exemple

Deux personnages possèdent :

> Mechanical 3D

Le premier possède :

> Piloting 5D

Le second possède :

> Vehicle Gunnery 5D

Ils possèdent des capacités mécaniques générales similaires, mais leur expérience est différente.

---

# 9. Mechanical et Technical

La distinction entre Mechanical et Technical est fondamentale.

## Mechanical

Mechanical permet principalement de :

> **utiliser et contrôler une technologie.**

Exemples :

* piloter un véhicule ;
* utiliser un capteur ;
* contrôler un système de navigation ;
* utiliser une arme montée ;
* manœuvrer un vaisseau.

---

## Technical

Technical permet principalement de :

> **comprendre, réparer, construire ou modifier une technologie.**

Exemples :

* réparer un véhicule ;
* modifier une arme ;
* programmer un système ;
* entretenir un moteur ;
* réparer une cybernétique ;
* effectuer une opération technique.

---

# 10. Pips et progression

Les pips sont conservés comme élément central du système.

Ils permettent une progression graduelle.

La progression suivante est possible :

```text
3D
   ↓
3D+1
   ↓
3D+2
   ↓
4D
```

Cette granularité permet de représenter des différences significatives sans imposer un dé supplémentaire à chaque amélioration.

Les pips sont particulièrement adaptés pour représenter :

* différents niveaux de compétence ;
* des améliorations techniques limitées ;
* des différences de qualité d'équipement ;
* des capacités cybernétiques.

L'utilisation de pips ne signifie cependant pas que les bonus doivent être systématiquement cumulés.

Une capacité technique doit autant que possible produire un effet clair et identifiable plutôt qu'une accumulation permanente de modificateurs.

---

# 11. Valeurs retenues pour la création

Un personnage joueur est créé avec :

## Attributs

**18D**

Répartis entre :

* Agility ;
* Strength ;
* Knowledge ;
* Perception ;
* Mechanical ;
* Technical.

Limites :

* minimum : **1D** ;
* maximum : **5D**.

---

## Compétences

**7D**

À répartir librement entre les compétences.

Limite :

* maximum de **3D supplémentaires dans une même compétence ou spécialisation lors de la création**.

Les pips sont autorisés.

---

# 12. Éléments exclus

Les éléments suivants ne font pas partie de la création de personnage :

* attribut Extranormal ;
* capacités psi ;
* pouvoirs surnaturels ;
* pouvoirs métaphysiques ;
* capacités magiques.

Les personnages joueurs sont humains.

Les différences entre personnages proviennent de :

* leurs attributs ;
* leurs compétences ;
* leur expérience ;
* leur équipement ;
* leur entraînement ;
* leur cybernétique.

---

# Résumé

La création d'un personnage suit les étapes suivantes :

## Étape 1

Répartir **18D entre les six attributs**.

Chaque attribut doit être compris entre 1D et 5D.

## Étape 2

Répartir **7D entre les compétences**.

Les compétences sont améliorées à partir de leur attribut associé.

## Étape 3

Choisir éventuellement des spécialisations.

## Étape 4

Compléter le personnage avec les éléments définis dans les chapitres suivants.

---

> **Décision de conception :**
>
> Le jeu conserve le moteur D6, les pips et la distinction entre attributs et compétences.
>
> Les personnages sont exclusivement humains et ne possèdent aucune capacité surnaturelle ou métaphysique.
>
> La spécialisation des personnages repose sur leur formation, leur expérience, leur équipement et, ultérieurement, leur cybernétique.
